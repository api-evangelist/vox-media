# Vox Media

> Vox Media is a modern media company (The Verge, Vox, New York Magazine, SB Nation, Eater, Polygon, The Cut, Vulture). Its developer surface centers on Coral — "Coral by Vox Media" — the open-source commenting and moderation platform used by 500+ newsrooms, which exposes a GraphQL API, HMAC-signed webhooks, embeddable comment components, and the coral-cli tool.

## APIs

- [Coral GraphQL API](https://docs.coralproject.net/api/schema): GraphQL API at https://{coral_domain}/api/graphql on each Coral instance; admin Bearer tokens via coral-cli; commenter identity via HS256 SSO JWTs.
